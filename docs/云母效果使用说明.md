# Windows 11 云母效果

程序从 [`main.cpp`](../main.cpp) 启动 `MainWindow`。窗口构造时，[`MainWindow::enableMicaEffect()`](../mainwindow.cpp) 通过 Windows DWM API 请求 Mica 背景，并保留系统标题栏。支持该效果的系统会显示半透明的浅色背景。系统无法启用该效果时，窗口继续使用默认背景。

[`FancyMainWindow.cpp`](../FancyMainWindow.cpp) 保留了带侧边栏的窗口原型。当前 CMake 目标使用 `MainWindow`，并编译 [`src/Fancy/`](../src/Fancy/) 中的界面组件。
